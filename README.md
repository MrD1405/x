
# SynergySpace

A virtual workspace platform - SynergySpace is a metaverse based virtual workspace platform designed to enhance productivity for employees in hybrid work environments, including both Work from Home (WFH) and Work from Office (WFO) setups. The platform will integrate tools for communication, collaboration, performance tracking, and employee well-being.




## Tech Stack

**Client:** React, Phaser, TailwindCSS

- Phaser is a 2D game framework. Phaser is an HTML5 game framework designed specifically for web browsers. It is built using, and relying on, web technologies. (https://phaser.io) 

**Server:** Node, Express

**Database:** MongoDB


## Run Locally

Clone the project

```bash
  git clone https://github.com/MrD1405/SynergySpace.git
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
  npm install
```

Start the server and client

```bash
  npm run dev
```


## Features

- Chat - using socket.io enabling real-time communication and supports file sharing
- Video and audio calls - using webRTC
- Virtual workspace - using phaser.js, created a game room
- Other features - authentication using jwttoken and others
